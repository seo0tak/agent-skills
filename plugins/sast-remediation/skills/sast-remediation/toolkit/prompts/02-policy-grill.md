# Project Policy Grill Prompt

```text
초기 분석에서 발견한 정책 공백을 SECURITY_GRILL_GUIDE.md 방식으로
확정해 주세요.

규칙:
1. 질문 전에 관련 소스, 호출부, 설정, 테스트와 PDF 가이드를 확인합니다.
2. 소스에서 확인 가능한 내용은 질문하지 않습니다.
3. 한 번에 질문 하나만 합니다.
4. 각 질문에 추천 답변과 선택별 영향을 포함합니다.
5. 내 답변을 project/PROJECT_SECURITY_POLICY.md와
   project/DECISION_LOG.md에 즉시 반영합니다.
6. 확정된 정책이 적용되는 모든 검출 ID와 작업 그룹을 갱신합니다.
7. 새로운 증거가 기존 정책과 충돌할 때만 같은 주제를 다시 질문합니다.

높음 이상 항목의 조치를 막는 정책부터 질문해 주세요.
```
