# Security Decision Log

결정은 한 항목에만 적용되는 임시 메모가 아니라 동일 조건에 재사용할 수 있도록
범위와 재검토 조건을 명시합니다.

## Decision Template

- 결정 ID:
- 결정일:
- 주제:
- 질문:
- 추천안:
- 결정 주체: 사용자 확인 | 기본안 적용(미확인) | 선택 무관 | 보류
- 확정 결정:
- 적용 범위:
- 근거:
- 확인한 소스, 명세 또는 증거:
- 영향받는 체커:
- 예외:
- 관찰 장치: (미확인일 때 — 어디에 무슨 로그를 넣었는지)
- 재검토 조건: (트리거 가능하게 — "무엇이 관찰되면 어떻게")

`결정 주체`는 반드시 채웁니다. 고민해서 내린 결정과 추천을 그냥 누른
결정이 여기서 구분됩니다. 검토자는 "기본안 적용(미확인)"만 골라 볼 수
있어야 합니다.
