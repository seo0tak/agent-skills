# 프로젝트 분석·정책 문서

초기 분석을 맡은 작성자는 이 폴더에 프로젝트 분석 결과와 사용자에게 확인받은
정책을 기록합니다. 템플릿을 복제해 확인한 내용으로 채우고, 추측으로 정책을
확정하지 않습니다.

- `INPUT_VALIDATION.md`: 현재 프로젝트와 입력 보고서의 적합성 및 시작 게이트
- `PROJECT_ANALYSIS.md`: 모듈, 계층, 빌드, 테스트, 외부 연동 분석
- `PROJECT_SECURITY_POLICY.md`: 현재 프로젝트에서 반복 적용할 확정 정책
- `DECISION_LOG.md`: 질문과 답변, 결정 주체, 근거, 관찰 방법의 시간순
  기록 — **직접 쓰지 않음**. 정본은 `../data/decisions.json`이고 이
  파일은 `sync`가 생성한다
- `WORK_GROUPS.md`: 충돌 없는 조치 묶음과 작업 순서
