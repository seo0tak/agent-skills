# 증적 워크북 컬럼 정의 (고정)

`prompts/05-final-evidence.md`가 생성하는 4개 워크북의 컬럼과 정렬
규칙입니다. 차수가 바뀌어도 이 정의를 유지해 증적의 일관성을 보장합니다.
프로젝트 사정으로 바꿔야 하면 이 파일을 수정하고 DECISION_LOG에
기록합니다.

## 공통 규칙

- 1행 = 헤더, 고정. 병합 셀 금지, 필터 사용 가능해야 함
- 정렬: 위험도(높은 순) → 체커 키 → 파일 경로 → 라인
- 위험도는 벤더 원문 표기와 표준 값을 함께 기재
- 날짜는 YYYY-MM-DD HH:MM

## 1. 전체조치결과 (allResults)

| 컬럼 | 내용 |
|---|---|
| 순번 | 1부터 |
| 검출 ID | 보고서 ID (차수마다 바뀜) |
| 고정 키 | stableKey — 차수를 넘는 동일 항목 식별자 |
| 위험도 | 원문(표준값) 예: 매우위험(critical) |
| 체커 키 / 체커명 | 보고서 그대로 |
| 파일 / 라인 / 함수 | 현재 소스 기준(이동 시 현재 위치) |
| 소스 매핑 | 일치/이동/변경/미발견/생성·외부 |
| 결론 | 수정/오탐/운영설정/예외처리/추가검토 |
| 진행상태 | 미착수~검증완료 |
| 조치 내용 | 변경 요약 또는 판단 근거 (1~3문장) |
| 검증 수단 / 검증 결과 | method / passed·failed·manual |
| 이월 여부 | 이전 차수 승계 시 이전 ID 표기 |

## 2. 오탐예외의견 (falsePositiveOpinions)

전체조치결과 컬럼 중 [순번, 검출 ID, 위험도, 체커 키/명, 파일/라인,
결론] + **제출용 의견**(감리·발주처 제출 문장, 2~4문장, 근거 코드
지점 명시) + **결정 근거**(DECISION_LOG 참조 ID).

## 3. 운영설정필요 (operationsRequired)

[순번, 검출 ID, 위험도, 체커 키/명, 파일/라인] + **필요한 설정**,
**담당 주체**(개발/인프라/운영), **확인 방법**, **기한 또는 조건**.

## 4. 미검증추가검토 (unverifiedReview)

[순번, 검출 ID, 위험도, 체커 키/명, 파일/라인, 진행상태] +
**미검증/보류 사유**, **필요한 후속 조치**, **권장 담당**.
