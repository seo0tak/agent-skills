# 합성 예시

이 폴더는 각 기록 형식을 설명하는 예시입니다. 파일별로 서로 다른 작업
단계를 보여주므로 한 프로젝트의 실제 완료 기록 묶음으로 복사하지 않습니다.
ID·명령·코드·시각·해시는 자리표시자 또는 합성 값입니다.

result.json과 progress.json의 verified는 기록 형식 예시이며 실제 테스트
성공 증거가 아닙니다. 소스 연결 없는 옛 결과가 어떻게 읽히는지도 보여줍니다.
실제 작업에서는 snapshot → 검증 실행 → 결과 기록 → seal-verification을
수행하고 status로 현재 소스 연결을 확인합니다. 실제 기록에는 자리표시자나 임의
값을 쓰지 않고, 대상 파일에서 계산한 해시를 사용합니다.

JSON 키·enum·응답 라벨은 도구 계약이므로 번역하지 않습니다.
판단 이유·적용 내용·영향·검증·비고는 사람이 읽는 문장으로 작성합니다.
미확인과 0건, 브라우저 초안과 정본, 데이터 검사와 실제 검증을 구분하세요.
