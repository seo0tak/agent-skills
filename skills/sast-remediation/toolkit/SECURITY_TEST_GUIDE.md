# SAST 검증 가이드

## 기본 원칙

검증 범위는 위험도보다 실제 변경 영향과 공유 범위에 비례합니다. 수정 파일이
작아도 공통 유틸리티, 인증, 암호화, 직렬화 또는 저장 형식에 영향을 주면 넓게
검증합니다.

## 프로젝트 명령 발견

초기 분석에서 다음 파일과 기존 자동화 설정을 확인합니다.

- 빌드 설정 파일과 빌드 도구가 제공하는 래퍼 스크립트(wrapper)
- 테스트 설정과 테스트 소스 루트
- 지속적 통합 설정
- 프로젝트 README와 개발 가이드
- 기존 유사 클래스 테스트

발견한 명령은 `project/PROJECT_ANALYSIS.md`와
`data/project-profile.*`에 기록합니다. 이 문서에는 특정 빌드 도구 명령을
고정하지 않습니다.

## 검증 근거를 현재 소스와 연결하기

검증 직전에 `sast_state.py snapshot --id <ID> --path <관련 파일>`을 실행합니다.
검증에 영향을 주는 소스·설정·테스트를 포함하고 실제 검증을 수행합니다.
방법·명령·출력·시각(verifiedAt)을 결과에 기록한 뒤 `seal-verification --id <ID>`로
연결합니다. 이 도구는 테스트를 실행하거나 검증 완료로 승격하지 않습니다.
파일이나 검증 근거가 바뀌면 다시 검증하고, 옛 결과의 연결 없는 검증도 그대로
신뢰하지 않습니다. 지정하지 않은 외부 환경·정책은 한계를 명시합니다.

## 검증 단계

### 1. 정적 확인

- 문법 오류와 누락된 import
- 타입 오류와 함수 계약 불일치
- 변경한 함수의 모든 호출부
- 사용하지 않는 코드와 도달 불가능한 분기

### 2. 관련 단위 테스트

- 정상 입력
- null 및 빈 값
- 경계값과 최대·최소값
- 잘못된 형식
- 예외와 정상 처리가 어려울 때의 대체 동작(fallback)
- 중복 항목을 함께 해소하는 조건

### 3. 호출 흐름 회귀

- Controller에서 Service까지의 검증 경계
- Service에서 Repository 또는 외부 연동까지의 반환 정책
- 저장과 조회 양쪽의 데이터 형식
- 직렬화와 역직렬화
- 암호화와 복호화

### 4. 보안 특화 확인

- 민감정보가 로그에 남지 않는지
- 권한 우회가 없는지
- 동시 요청에서 상태가 섞이지 않는지
- 기존 암호문과 저장값이 호환되는지
- 외부 명세의 바이트, 문자셋, 필드 길이를 유지하는지

### 5. 넓은 검증

공통 컴포넌트 또는 여러 모듈에 영향을 주면 관련 모듈 테스트와 가능한 전체
테스트를 실행합니다.

### 6. 간단 기동 확인(runtime smoke, 선택)

로컬 또는 개발 환경에서 애플리케이션 기동이 가능하면, 수정 범위가 큰
조치 실행을 마친 뒤 실제로 기동해 확인합니다.

- 애플리케이션이 정상 기동하는지 (기동 로그의 에러·경고)
- 변경과 관련된 핵심 화면 또는 엔드포인트 1~2개가 응답하는지
- 설정 변경(예: 하드코딩 비밀번호 제거 → 외부 주입)이 기동에
  반영되는지

기동이 불가능한 환경(운영 전용 설정, 외부 시스템 의존)이면 사유를
  `limitations`에 기록하고 생략합니다. 이 수단을 쓰면
  `verification.method` 값은 `runtime-smoke`로 기록합니다.

## 테스트를 추가할 기준

다음 중 하나에 해당하면 회귀 테스트를 우선 추가합니다.

- 검출 흐름을 재현할 수 있음
- null, 경계값 또는 잘못된 입력 방어를 추가함
- 예외 처리 또는 대체 동작이 변경됨
- 외부 입력을 정규화함
- 변경 가능한 상태, 동시성 또는 캐시를 변경함
- 암호화, 해시, 인코딩 또는 직렬화를 변경함

단순 선언 변경이나 스캐너 오탐 증적처럼 실행 동작이 바뀌지 않는 경우에는
기존 테스트와 컴파일 검증으로 충분할 수 있습니다. 이유를 결과에 기록합니다.

## 검증 실패 처리

- 기존 실패인지 변경으로 인한 실패인지 구분합니다.
- 외부 시스템, 라이선스, 네트워크 또는 운영 데이터가 필요하면 자동화 불가
  사유와 수동 검증 절차를 기록합니다.
- 실패한 상태에서 `verified`로 표시하지 않습니다.
- 일부만 검증했으면 실행한 범위와 남은 위험을 명시합니다.
