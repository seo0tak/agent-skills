## 최종 판정

`READY`는 모든 필수 파일이 유효하고, 현재 소스와 선택 보고서가 같은
프로젝트와 검사 차수를 가리키며, 검출 목록을 정규화할 수 있을 때만
선언합니다. 근거가 부족하거나 불일치가 있으면 `BLOCKED`로 두고 다음
단계로 진행하지 않습니다.
