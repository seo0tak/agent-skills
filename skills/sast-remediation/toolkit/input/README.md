# 이번 차수 입력

현재 소스는 툴킷 밖의 프로젝트 루트에 두고, 이 폴더에는 다음 중 한 세트를 넣습니다.

- PDF·스프레드시트 모드: 상세 PDF 1개 이상 + 검출 목록 스프레드시트 1개
  (Sparrow 보고서 기준 안내 포함)
- SARIF 모드: 표준 `.sarif` 1개. PDF는 선택 사항입니다.

분할 PDF는 모두 같은 프로젝트·분석 차수여야 합니다.
여러 세트는 `input/<세트명>/`으로 나눕니다. 여러 폴더가 있으면
`preflight --input-set <세트명>`으로 하나를 지정합니다.
서로 다른 차수를 한 세트로 합치지 않습니다.

AI에게 `prompts/00-preflight.md`를 전달하면 파일 형식 점검 후
프로젝트·검사 차수·검출 건수·소스 범위를 대조합니다.
파일 개수가 맞다는 사실만으로 READY를 선언하지 않습니다.
입력 변경 후에는 승인과 내용 해시를 다시 확인합니다.

보고서에 없는 정보는 “미확인”으로 남기며 0건이나 해당 없음으로 채우지 않습니다.
이전 차수 자료는 별도 보관하고, 이월은 `prompts/06-carry-over.md`로 요청합니다.
