# 추천 작업 목록 스크롤 개선

- 기준 커밋: `f065d76`
- 배포 버전: sast-remediation 1.12.3; skill-architect 0.4.2는 변경 없음
- 승인 범위: 앞서 검토한 추천 목록 스크롤 개선을 적용하고 main에 푸시

## 원인과 변경

기존 추천 목록은 ‘전체’ 선택 시 모든 진행 대상을 렌더링하지만 높이 제한이
없어 페이지가 길어졌다. 아래 검출 표에는 이미 내부 스크롤이 있었다.

- 추천 목록 본문에 `max-height: min(50vh, 480px)`와 `overflow-y: auto`를 적용했다.
  짧은 목록은 자연 높이를 유지하며 5/10/20/전체 모두 같은 규칙을 사용한다.
- 제목·설명·표시 개수 선택기는 목록 밖에 둔다. 목록에는 키보드 초점,
  영역 이름·스크롤 안내와 초점 윤곽을 제공한다. 기본 휠/터치 스크롤 연결은 유지한다.
- 목록을 다시 그릴 때 스크롤 위치를 복원하고, 표시 개수를 변경할 때만 0으로
  초기화한다. 빈 목록은 위치를 0으로 정리하며 줄어든 목록의 범위 조정은 브라우저에 맡긴다.
- 추천 대상·정렬, 검출 표 필터·페이지, 입력/상태/저장 형식과 권한은 변경하지 않는다.
  전체 선택은 여전히 전체 추천 항목을 생성하며, 가상 목록이나 페이지 분할은 추가하지 않았다.

## 검증 근거와 한계

Node VM에서 실제 추천 렌더링 함수와 이벤트 처리기를 호출하는 5개 검사를 추가했다.
문서/스타일의 특정 문자열 존재를 동작 시험으로 대신하지 않았다.

- 변경 전: 기존 동작을 지키는 3개 검사는 통과. 표 필터/정렬과 상세 상태 갱신 시
  스크롤 위치를 복원하는 2개 검사는 예상대로 실패했다(640 → 0).
- 변경 후: 5개 모두 통과. 표시 개수와 제외 상태, 독립적인 표 필터·페이지,
  상세 버튼 포커스 복귀, 스크롤 유지/초기화와 빈 목록을 확인했다.
- DOM 대역은 자식 제거 시 연결 해제와 빈 스크롤 영역의 위치 초기화를 모델링한다.
  실제 화면의 높이·잘림·포커스 자동 스크롤을 계산하는 브라우저 엔진은 아니다.

이전 로컬 파일 URL 접근이 브라우저 정책으로 차단되어 다른 경로로 우회하지 않았다.
따라서 390/1024/1440px 화면, 확대, 휠/터치/키보드 스크롤과 초점 윤곽의 실제
렌더링 시험은 미실행이다. CSS/HTML 구조 검토와 JavaScript 동작 검사의 범위를 구분한다.
현재 세션에 LSP 도구도 노출되지 않아 관련 호출부를 제한된 검색으로 확인하고
JavaScript 문법 검사·회귀 검사로 검증한다. 설치된 플러그인·프로젝트 복사본은 갱신하지 않는다.

## 최종 검사와 독립 리뷰

- 정본 회귀 검사 165개 통과: SAST Python 83개, 대시보드 Node 57개,
  skill-architect Python 24개, 패키징 1개.
- 플러그인 배포 사본의 대시보드 검사 57개도 통과했다.
- JavaScript 문법 검사, 버전 일치, 정본/배포 사본 일치, 변경 파일 공백 검사 통과.
  툴킷 검증은 통과했으며 배포 템플릿의 빈 입력에 대한 예상 경고 1건이 있었다.
- 표시 개수 변경 시 초기화 코드를 메모리에서만 제거하는 변이 검사에서 해당
  회귀 검사가 예상대로 실패했다(920 → 0 기대, 실제 920). 원본 파일은 변경하지
  않았으며 정상 코드로 전체 대시보드 검사 57개를 다시 실행해 통과했다.
- 독립 리뷰에서 변경이 필요한 결함은 발견되지 않았다. 검토자는 새 검사 5개,
  JavaScript 문법 검사와 변경 파일 공백 검사를 별도로 실행해 통과를 확인했다.
  위에 명시한 실제 브라우저 검증 한계를 전제로 병합 가능으로 판단했다.
